## 简体中文

Excel Tools 是一款用于批量处理 Excel/CSV 数据的浏览器扩展。

当前版本主要支持：

- 为指定列批量添加前缀
- 为指定列批量添加后缀
- 处理前预览结果
- 导出处理后的文件
- 所有数据均在浏览器本地处理，不会上传服务器

更多快捷操作将根据用户反馈逐步推出。

## English

Excel Tools is a browser extension for batch-processing Excel and CSV data.

The current version mainly supports:

- Adding prefixes to selected columns
- Adding suffixes to selected columns
- Previewing results before processing
- Exporting processed files
- Processing all data locally in your browser without uploading files to a server

More quick actions will be introduced gradually based on user feedback.

### Feedback and feature requests

If you encounter a problem or would like a new quick action, please submit it through GitHub Issues.

- [Report a bug](https://github.com/chouyingying73-byte/excelTools/issues/new?template=bug_report.md)
- [Request a feature](https://github.com/chouyingying73-byte/excelTools/issues/new?template=feature_request.md)
- [View existing issues](https://github.com/chouyingying73-byte/excelTools/issues)

Before submitting:

1. Search existing issues to avoid duplicates.
2. Do not upload Excel files containing names, phone numbers, order numbers, account information, or confidential business data.
3. Remove or anonymize sensitive information from examples.
4. Keep each issue focused on one problem or request.
5. For bugs, include reproduction steps, the extension version, and the browser version whenever possible.

Your feedback helps us decide what to build next.
